How to Connect from Client Websites

Use the code snippets below in your client website to compress images via your Micky Compressor API.

1. JavaScript (Fetch API in Client Website)

// From your client website
async function compressImage(file) {
  const formData = new FormData();
  formData.append('file', file);
  formData.append('quality', '80');

  const res = await fetch('https://your-domain.com/api/compress', {
    method: 'POST',
    headers: {
      'x-api-key': document.getElementById('key')?.textContent || 'YOUR_CLIENT_API_KEY'
    },
    body: formData
  });

  if (!res.ok) throw new Error('Compression failed: ' + res.statusText);
  const compressedBlob = await res.blob();
  return compressedBlob;
}

2. cURL (Terminal / Backend)

curl -X POST https://your-domain.com/api/compress \
  -H "x-api-key: YOUR_CLIENT_API_KEY" \
  -F "file=@photo.jpg" \
  --output photo-min.jpg

3. Automatic Free Monthly Reset

  • TinyPNG: Free 500 compressions/month. TinyPNG automatically resets the count on the 1st of every month at 00:00 UTC.
  • ImageKit: When TinyPNG reaches 500, requests seamlessly fail over to ImageKit (20 GB monthly free bandwidth).
  • When the new month starts, TinyPNG quota is full again and gets prioritized automatically!
